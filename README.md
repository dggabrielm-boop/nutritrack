# NutriTrack

Aplicación web responsive de planificación y seguimiento nutricional.

> Esta entrega contiene la arquitectura, el wireframe funcional y la estructura inicial del repositorio. La implementación definitiva queda para la siguiente etapa.

## Estado

- Fase: definición y prototipado
- Plataforma inicial: GitHub Pages
- Persistencia V1: `localStorage`
- Backend/cuentas: fuera del MVP
- Alcance: planificación, registro y educación nutricional; no diagnóstico ni dieta médica
