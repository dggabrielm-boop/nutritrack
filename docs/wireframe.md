# Wireframe funcional — V1

El prototipo de `prototype/index.html` representa la navegación y las interacciones principales. Su objetivo es validar jerarquía, recorrido y cantidad de información antes del diseño visual definitivo.

## Navegación móvil

```text
┌──────────────────────────────┐
│ NutriTrack              ⋯    │

│                              │

│ Almuerzo        + Registrar  │

```

## Vistas y acciones

### Hoy

- Ver calorías y macros acumulados.
- Registrar agua, pasos y peso.
- Abrir una comida existente.
- Iniciar una comida nueva.

### Comidas

- Elegir tipo de comida.
- Seleccionar proteína, acompañamiento, vegetales y grasa.
- Ajustar porciones.
- Ver total en tiempo real.
- Guardar, marcar como favorita o reemplazar alimentos.

### Actividad

- Registrar entrenamiento, minutos, pasos y sueño.
- Registrar hambre antes y saciedad después de una comida.

### Evolución

- Cambiar rango: 7 días, 30 días, 90 días.
- Consultar peso, calorías, proteína, agua y entrenamientos.
- Ver promedio semanal y consistencia.

### Perfil

- Editar datos corporales.
- Cambiar objetivo, actividad y comidas por día.
- Editar objetivos manuales.
- Agregar alimentos personalizados.
- Exportar/importar datos.

## Criterio de validación del wireframe

Se considera aprobado si una persona puede completar este recorrido sin ayuda:

1. Configurar perfil.
2. Llegar a Hoy.
3. Crear y guardar una comida.
4. Ver el impacto en calorías y proteína.
5. Registrar agua y peso.
6. Consultar Evolución.
